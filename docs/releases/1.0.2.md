# LucidMic 1.0.2

**Unreleased local candidate.** Public download links still point to 1.0.1.

This update adds input selection and fixes growing audio delay, failures when
devices disconnect, and incomplete offline recordings.

## What's changed

- **Choose your input in Settings.** Select a physical microphone and, for
  devices with multiple inputs, its channel. Changing either briefly restarts
  routing and preserves your Noise Removal setting.
- **Recover from device failures.** If a microphone disconnects or stops working,
  routing stops and the menu shows an error. Reconnect it or choose another input,
  then enable **Noise Removal** to retry. Failed default-input changes are reported.
- **Check compatibility before starting.** Inputs must support 48 kHz audio and
  buffers of 512 frames or fewer. Unsupported configurations produce a clear error.
- **Keep delay predictable.** Disabled streams no longer crash audio processing;
  processing stalls recover without leaving old audio queued. The engine adds
  **72 ms** of delay; audio devices and call apps can add more.
- **Save complete recordings.** The offline file tool preserves the recording's
  duration and ending, mixes all source channels into mono, and writes 48 kHz WAV.
- **Improve installation and packaging.** Driver replacements are staged and
  validated before replacing an existing installation. The bundled runtime omits
  unused speech-synthesis components; model and inference-library versions are unchanged.

Unchecking **Noise Removal** continues to pass original audio through. It does
not mute the microphone.

## Try the local candidate

Requires **Apple silicon** and **macOS 14 Sonoma or later**.

Build with `scripts/build.sh 1.0.2`, or use a locally supplied
**LucidMic-1.0.2.dmg**. Quit an older LucidMic, open the DMG, and drag the new app
into Applications. Open it and enable **Noise Removal** from the waveform menu.

The app is ad-hoc signed and not notarized. If macOS blocks first launch, try
opening it, then use **System Settings → Privacy & Security → Open Anyway**.
First use asks for microphone access and administrator permission to install the
virtual microphone. Install before a call: setup restarts the audio service.

In a call app with a manually selected input, choose **LucidMic Microphone**.
Apps using the system-default input receive LucidMic audio automatically.
