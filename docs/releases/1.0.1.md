# LucidMic 1.0.1

**Your voice. Minus the noise.**

A native macOS menu makes LucidMic quicker to read and easier to control.

## What's new

- **Noise Removal** is a checkmarked menu command, with clear status and your current microphone underneath.
- **Settings…** contains launch at login and virtual-microphone removal. Removing the microphone asks for confirmation.
- **How to Use LucidMic** works offline; **About LucidMic** shows version information.
- Standard keyboard commands include **⌘,** for Settings and **⌘Q** to quit.
- Updated light/dark repository previews and shorter credits.

Noise removal and its bundled model are unchanged. Unchecking **Noise Removal**
passes your original audio through; it does not mute or disconnect the microphone.

## Install or update

Requires **Apple silicon (M1 or newer)** and **macOS 14 Sonoma or later**.

1. Quit an older LucidMic before replacing it.
2. Download **LucidMic-1.0.1.dmg**, open it, and drag LucidMic into Applications.
3. Open the app and enable **Noise Removal** from the waveform menu.

The app is ad-hoc signed, not notarized. If macOS blocks first launch, try opening
it and then choose **System Settings → Privacy & Security → Open Anyway**.

First use asks for microphone access and administrator permission to install the
virtual microphone. Setup restarts the audio service, so install before a call.
Apps using the system-default input receive cleaned audio; otherwise, choose
**LucidMic Microphone** in the call app's audio settings.

## Downloads and source

- **LucidMic-1.0.1.dmg** — the app, model, inference libraries, and virtual microphone.
- **SHA256SUMS.txt** — checksums; download all three listed artifacts and run `shasum -a 256 -c SHA256SUMS.txt`.
- **BlackHole-0.7.1-source.tar.gz** — source for the bundled virtual microphone driver.
- **LucidMic-1.0.1-runtime-source.tar.gz** — pinned source for sherpa-onnx and its embedded dependencies, with build provenance.
- The separate [ONNX Runtime v1.28.2 source](https://github.com/microsoft/onnxruntime/archive/refs/tags/v1.28.2.tar.gz) is hosted upstream.
- GitHub's **Source code** archives contain LucidMic and its build/customization scripts.
