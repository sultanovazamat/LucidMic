# LucidMic 1.0.0 release plan

Status: approved by the repository owner in the Codex conversation.

Follow-up: keep the repository private and match the author's Bilby README format.

Goal: publish a polished, freely available macOS app at sultanovazamat/LucidMic,
with a 1.0.0 DMG, consistent branding, and verified installation metadata.

## Implementation

1. Create a blue/cyan microphone monogram; package the logo, app icon, README
   banner, and matching drag-to-Applications artwork.
2. Publish GPL-3.0 source, complete dependency notices/licenses, a concise README,
   contribution instructions, changelog, and CI/release workflows.
3. Pin downloads, build 1.0.0, verify its resources and signature, and attach the
   DMG, checksum, and BlackHole source archive to the release.
4. Update the installed application, refresh registration/indexing, and verify
   Spotlight discovery without resetting the whole system index.

## Spotlight issue

Expected: searching for LucidMic finds /Applications/LucidMic.app.
Actual: the installed 0.1.0 bundle is registered with Launch Services but has no
Spotlight result/metadata; Calculator is indexed correctly. The installed copy
also predates the app-icon metadata in the current build.
Initial hypothesis: missing or stale app-specific indexing. Follow-up diagnostics
found the Data volume's indexing disabled and other Applications entries missing;
the Spotlight importer successfully parses LucidMic's app metadata. Enabling
indexing requires macOS administrator authentication.
Minimal fix: replace the old bundle with the release, register it and request
targeted import; change metadata only if diagnostics demonstrate a defect.
Blast radius: installed bundle, bundle metadata, and installation documentation.
Regression check: query metadata and search for the installed bundle, then launch
by bundle identifier. A missing icon alone does not prove the indexing cause.

## Acceptance and verification

- Existing engine tests pass; formatting, lint, compilation, and packaging checks pass.
- The DMG contains an arm64 1.0.0 app, logo, model, libraries, driver and licenses.
- Public README download links resolve to the published release.
- Published assets match local SHA-256 checksums; driver source matches the build.
- Spotlight outcome is verified and any unresolved limitation is reported.
- Ad-hoc signing and its first-launch steps are clearly disclosed.
